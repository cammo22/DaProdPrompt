# DaProdPrompt

**DaProdPrompt** è una slot machine creativa per generare prompt completi in pochi secondi. Combina un ruolo, un obiettivo e uno stile per trasformare una semplice idea in una richiesta pronta da usare con il tuo assistente AI.

[![Apri DaProdPrompt](https://img.shields.io/badge/Apri%20l'app-GitHub%20Pages-2ea44f?style=for-the-badge)](https://cammo22.github.io/DaProdPrompt/)

## Come funziona

1. Premi **Gira la slot machine**.
2. Lasciati ispirare dalla combinazione generata.
3. Premi **Copia prompt** per portare il risultato negli appunti.

Il progetto è una singola pagina HTML, senza dipendenze o installazione: è veloce, leggero e facile da personalizzare. Il pulsante di copia usa la Clipboard API quando disponibile e un fallback compatibile per contesti non sicuri.

## Sviluppo locale

Apri `daprodprompt.html` direttamente nel browser oppure avvia un server statico nella cartella del progetto. L'accesso da `index.html` resta disponibile tramite reindirizzamento. Le modifiche vengono pubblicate automaticamente su GitHub Pages a ogni push su `main` tramite GitHub Actions.
